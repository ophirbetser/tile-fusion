# tile-fusion

A sliding-tile merge puzzle for the browser.

## How to play
- Use the **arrow keys** (or WASD, or swipe on a phone) to slide all tiles.
- Two tiles with the same number fuse into one with double the value.
- Reach the **2048** tile to win, and keep going for a high score.

## Run locally
Open `index.html` in a browser. No build step needed.
